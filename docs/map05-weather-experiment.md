# 05 森壁の回廊 — 雨で閉じる森の門（Issue #61 / 親 #38）

採用根拠：親 #38 の「05 森壁の回廊 — 晴れと雨で価値が変わる経路」、分割 #61。
2026-10-22夜のはねさんの追加指示「多少最初の意図から変わっても、SRPGとしてバランスや戦略を考える面白さがあるゲームとして面白いものにしたい」に従い、
**複数の作戦がそれぞれ別の代償で成立すること**を優先して評価した。基準main `74ca3b3`。危険度medium。

## 改修前の問題（同一方策で実測）

- 通常前進はT25勝利・無交戦8ターン。慎重・「大雨で止まる」方策は35ターンで未決着（無交戦17〜20ターン）。
- 守将（上級盾・防御2）が勝利マス上に静止。味方の攻撃はほぼ1ダメージずつで、終盤が長い消耗戦になる。
- 北の盾・弓は城の直前に置かれ、2回目の晴れ（T6–7）は交戦のない移動で終わる。東回廊の守備隊は岩壁沿いに寄るだけ。
- 雨は「足が遅くなる」以外の意味が薄く、どこで雨を迎えるかの判断が盤面に表れにくい。

## 城の守備兵（PR #62 監督レビューで追加、2026-10-23）

監督レビューで、守将を城門前に出した結果**北城が空き**、マップ両端の草地（x=0–1／14–15、旧版から存在）を騎兵が駆け上がると
**一度も戦わずにT7で城を取れる**ことを確認した（騎兵2隊のうち1隊が囮で倒れ、残る1隊が制圧。標準前進T16より9ターン速い）。
旧mainでは守将が城の上にいたため成立しない。

はねさんの決定（2026-10-23、PR #62）：
> 「それでいいよー！面白そう。ただシステム的に統一感は持たせたいしシナリオのメリハリもできそうなので、05、一応主将を倒さない場合は、雑魚が1人いるぐらいだといいかな？そこはお任せ！」

これに従い、**「守将が城の上にいないマップでは、城のマスに雑魚1体」**を置いた。05では下級の弓兵1隊（新しい固定ID `castle-guard`、hold、通常能力）。
弓を選んだ理由（同一方策で剣・盾・弓・騎兵・魔術師を比較）：
- 弓は射程2のみなので、隣に入った近接部隊には反撃できない。「城の上の雑魚を倒す一戦」で済み、守将ほど重くない。
- 盾は大雨方策がT27・3隊離脱、敵攻撃+1で全方策未決着になり重すぎた。剣・騎兵は大雨方策がT26・3隊離脱。魔術師は弓とほぼ同じだが通常前進の離脱が2。
- 戦わない騎兵の駆け上がりは、どの端・1〜3騎でも35ターン以内に城を取れなくなった（`tests/map05-weather.test.js` で固定）。
  城の弓兵を倒しに行く騎兵奇襲は最短T9で成立するが、出した騎兵・剣の大半（2隊）を失う。速さと損害を引き換えにする別解として残した。

マップ02・03（統合済み、守将が城門前）も同じ規則にそろえるべきだが、このPRでは変更しない（別Issueで対応）。

## 作戦の比較（35ターン上限、標準難易度、同一エンジン）

`npm run simulate` と同じ `play()`。改修前は同じ方策で上の6か所だけ戻した完全な旧マップ。全値は [map05-weather-results.json](map05-weather-results.json)。

城の守備兵を含む値。守備兵を置く前は通常前進T16・慎重T17・大雨T17（離脱0）・東T17・騎兵T21だった。
通常前進のT1敵攻撃は0（騎兵先行は2）。どの勝ち方も大雨のターンに交戦かP3があり、前進は晴れのターンに集中する（`tests/map05-weather.test.js` で固定）。

### それぞれを選ぶ理由（代償の違い）

- **通常前進**：T18。雨の中でも前に出るので弓を1隊失う。
- **大雨で止まる**：T17・離脱1。砲兵・魔術師を先に出して雨の間を支援に使う。旧マップでは止まるほど停滞したが、試作では「止まって支え、晴れで押す」が報われる。**敵攻撃+1では、この方策だけがT21で勝ち、通常前進・慎重は35ターンで未決着**（テストで固定）。難しいほど天候を読む価値が上がる。
- **東回廊**：西の守備線を避けて東の街道を進む別解。T20・離脱2（剣と騎兵）。どちらの回廊にも勝ち筋と危険がある。
- **騎兵先行・P3なし**：P3を使わなくてもT18で勝てるが、騎兵2隊と弓を失う。速さは同じでも損害が3倍。
- **騎兵の奇襲**（方策表外・監督レビューの探索）：騎兵2隊で端の草地を駆け上がり城の弓兵を倒すと最短T9だが、2隊を失う。
- **慎重**：旧マップでは城前で止まり続けたが、守将が城門前に出たことでT17に勝てる。

難易度の参考（同じ方策、改修前→試作）：敵攻撃+1では通常前進が未決着→未決着、大雨で止まる方策が未決着→T21勝利、慎重は未決着のまま、騎兵先行が未決着→T22。敵攻撃−1では全方策T15〜17勝利。

## 保存と互換

- 寸法・地形の通行可否・敵ID/兵種・味方構成が変わらないため、旧v0.8途中保存はそのまま読める。既存の読込規則どおり部隊の位置・HP・AIは保存のまま、地形と守備の基準位置だけが現行になる。
- 旧保存で守将が(8,1)にいる場合、守将はholdなのでそのまま北城上に残る（旧来どおり倒して制圧）。
- 城の守備兵 `castle-guard` は新しい戦闘から現れる。旧保存の途中の戦闘には部隊として追加しない（保存された部隊の位置・HPをそのまま使う既存規則どおり。旧保存の多くは守将が城の上にいる）。テスト：`tests/map05-weather.test.js`。
- 地形固定テスト `tests/issue17.test.js` は、歴史的fixtureを残したまま、05だけ新しい正確な地形 `tests/fixtures/map05-current-61.json` と照合する（01と同じ扱い）。旧地形との差が森の門8マスだけであることも別に検査する。

## 未検証・試遊で見てほしいこと

iPhone Safari実機、タッチ操作量、人間にとっての面白さ・難度、独立監査は未検証。方策AIの勝利は面白さの証明ではない。

1. 晴れの2ターンで前に出て、雨の直前にどこで止まるか迷えるか。大雨で盾・弓・魔術師が森の門に入れないことが移動範囲で読めるか。
2. 大雨のターンに砲兵・魔術師を止めてP3で支えることに意味を感じるか。雨のターンが「待つだけ」になっていないか。
3. 雨上がりの晴れに城へ回り込む／守将を削る、の選択が気持ちよいか。守将を倒さずに城を取れることが拍子抜けでないか（02と同じ論点）。
4. 西の守備線を正面から崩すか、東回廊へ回るか。東回廊が別解として魅力的か。
