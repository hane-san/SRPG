# マップ02 防衛から反攻へ — 敵配置の比較試験（Issue #38）

2026-10-22。現在の02「二つの戦線」（16×30）について、地形・寸法・味方の初期出撃・HP6/P3/フェーズを**変えず**、敵軍の守備位置だけで本陣防衛と北城攻略の意味が立ち上がるか試した。

## 課題と仮説

現行mainは本城を守るために盾を残す判断自体には意味があるが、北城の目標座標 (8,1) に守将が静止し、別の盾が狭い北進路を塞いでいる。現在の貪欲方策では城に近づいてから動きが止まり、慎重に守ることが無限の足止めになりやすい。

**仮説：** 城門前の将と北西の守備隊を分離すれば、正面の守備を崩す選択と城を先に制圧する機動戦が生まれる。同時に南城からの予告増援は残すため、無防備の全軍北進は負け得る。

## 同一エンジンの決定論比較（実行済み）

GitHub mainで取得した `config.js` / `data.js` / `engine.js` / `tests/simulate.mjs` / `tests/tactical-observer.mjs` をV8で結合して実行。**同じ規則・難易度・方策**（ただし開始時の敵配置のみ変更）、40ターン上限。ここでの比較は関数単位の再生であり、正式なGitHub Actions `rules/browser` やiPhone実機の代わりではない。

| 方策 | 従来 | 試作 |
| --- | --- | --- |
| 通常前進（advance） | T40実行後も未決着、味方離脱3 | **T11勝利、味方離脱1** |
| 慎重な前進（cautious） | T40実行後も未決着、味方離脱4 | **T11勝利、味方離脱1** |
| 本城を意識した前進（base） | T40実行後も未決着 | **T11勝利** |
| 全軍攻勢（offense） | T6本陣陥落・敗北 | **T6本陣陥落・敗北** |
| 東道先行（east） | T40実行後も未決着 | T14本陣陥落・敗北 |
| 南城先制（south） | T40実行後も未決着 | T40実行後も未決着 |

**読取り方：** 防衛しつつ北上する方策には明確な成功例が生まれ、全軍攻勢には引き続きリスクがある。ただし、このAIの「慎重」は最適な人間の慎重進軍ではない。東道・南城先制は今回の改善で救済されておらず、**別解の豊かさは未完成**。守将を倒さず城を奪える場合があるので、勝利が拍子抜けしないかも人間が判定する。

### 採用しなかった有力な試案

- 守将 (8,2) ＋ e4 (5,4)：通常前進はT12勝利・離脱1だが、慎重策は停滞。両立できる (7,2) 案を試す。
- 守将 (8,1) 維持のまま北衛 e4 を前後左右へ移動：評価した候補では通常方策の長期停滞が残った。
- 北の敵を両方前進AIに変更：敵が先に集中しすぎて通常前進も早期に敗北。序盤の理不尽な集中を復活させない。
- 増援停止や戦闘数値変更：守備の意味を消してしまうため今回は採用せず、シンプルな配置で検証する。

## 連戦・ネームド喪失の追加検証

01でネームドが戦死し、次章に同兵種の一般兵が入る条件も、同じ決定論方策で試した。

- `lost=['a1']`（盾）：**T11勝利**。このケースをNode自動テストに固定した。
- `lost=['a3']`（弓）や `lost=['a4']`（魔術師）：**T11勝利**。
- `lost=['a2']`（剣士）：同じ自動方策では **T15本陣陥落の敗北**。一般兵は基本戦力を引き継ぐが、IDによる選択順などAI方策の差が出る。**ゲーム全体が攻略不能との証拠ではない**。別の出撃順・実プレイヤー操作で本陣防衛可能か、連戦プレイテストで優先確認。
- 重要：一般兵の性能保証は既存のルール。固有キャラが誰か失われても「自動方策ひとつで必ず同じ勝ち方」までは要求しない。ただしロストにより本編攻略が不可能になる設計は避ける。

4. `npm run check` / `npm run simulate` / `npm run test:browser` / CIを最新headで確認。ChromiumはSafari実機ではない。
