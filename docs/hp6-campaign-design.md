# 英雄叙事詩（戦線指揮プロトタイプ）— HP6・出撃・ロスト仕様 / 2026-10-18

## 目的と優先順位
- **読みやすさ**: 最大HPは敵味方全員6。盤面の6ピップから攻防の組合せを読む。乱数・命中/必殺・一般的な守備値と地形守備は導入しない。
- **戦術**: 部隊の出撃順と予備、攻勢・撤退・拠点防衛が意味ある選択になる。4フェーズと移動/攻撃/待機の短い操作を維持。
- **戦力保証**: ネームド戦死は永久喪失、だが兵種枠は次章に一般兵で補充。戦死修理費・戦果報酬減額は**廃止**。
- **奥行きの報酬**: メインは一般兵だけで完走できる。上手なプレイヤーには戦術選択と外伝・回想・隠し人物など「知り得る物語」を拡張する報酬。
- **制作順**: HP6・補給・出撃と簡単な昇格選択を先に検証。兵種細分化・サブマップ報酬・最終章の台本は**今は作らない**。

## 敵戦力の恐怖の曲線
1. 序盤は2+2+2=6という小さい戦闘計算を覚える。
2. 第4〜6章相当で初めて攻撃3の敵が出て、二撃壊走の怖さを知る。
3. 自軍にも3が揃い、強さに慣れる。
4. 敵の3のままでも射程・地形・連携・増援によって脅威が再燃する。
5. 物語上の重いボスだけ4〜5を持つ。5+1=6がわかるようになる。
現在の3章キャンペーンはこの全体曲線ではなく試作範囲。数値と配置はプレイテスト対象。

## ネームド永続ロストと報酬
- 戦死はキャラの人格・その後の会話・外伝の条件の喪失。基本兵種枠・攻略に必要な数値は失わない。
- 将来、上手さへの報酬を「追加の戦術選択肢／有利な位置取り／困難なサブ目標の達成／外伝や隠しキャラ」に配分する。
- 基礎の成長は全員保証。上級職の標準能力は、下級より基本的には上位互換。ネームドだけ技能分岐があり、一般兵は標準型で止まる。
- 永続ロストと修復費減額を重ねない。戦闘をわざと下手にすることで有利になる救済報酬は作らない。
- 重要な世界観・結末は外伝未達でも理解できる。外伝は理解を深めるもので本筋の穴埋めではない。

## 物語の作法（**未実装**）
### 将軍
- 主人公の傍で作戦を支える将軍は、本編で仲間が失われても出撃しない。自ら本城に残り全局面を指揮する方が、戦争全体にとって合理的だと深く理解しているため。
- 最終章だけ、その将軍が出撃。本城に押し寄せる、数章前に倒された名ヴィランを慕う残党の決死の蜂起を食い止めるのが最も合理的だから。自身の討死を覚悟している。
- 主力軍は育てた全部隊でラスボスへ総力戦。プレイヤーは「遠距離から延々と雑兵を倒して遅延する」のではなく、将軍が稼ぐ有限の時間を感じながら戦う。
- 本城側は強烈かつ継続する攻勢（設計上無限増援）、本城に残した味方や戻した味方の存在は実際の戦闘で意味を持つ。
- **将軍の生存エンディングは作らない**。討死の決意と人格の一貫性を守る。将軍がゲーム内で倒れた場合と、ラスボス早期撃破で生き残って決着に合流した場合とでは、そこに至る描写・人命・最期までの会話・回想が異なる。
- 将軍がラスボスに主人公がとどめを刺す瞬間に間に合った場合のみ、思想と物語の根幹を示す濃い場面・回想を追加。最後には自ら殉ずる。勝敗の大筋は変えず、プレイヤーの働きが感情的な真実を変える。
- **固定された犠牲を、プレイヤーの頑張りをなかったことにする強制イベントにしない**。サブ目標や生存経路、対話の厚みなどで努力を報いる。残党にも忠誠と戦う理由を与える。
- 具体的なシナリオ、将軍・主人公の名前、最終章戦闘スクリプト、無限増援は後日。バトル実装へ勝手に混ぜない。

## 実装上の検証課題
- プレイヤーの選択が「最初から全隊を出す」の一択にならないか。
- 出撃前の予備ユニットは座標を持つが盤面占有せず、敵AIや危険域にも出ないこと。
- 反撃・待機・回復が1ターンに二重発火しないこと。
- 初期2隊からでも序盤のマップが理不尽に難しくならないこと。
- 一般兵に置き換わっても最終的にクリア可能であることは、特定の自動プレイでの検証だけでは証明できない。人間プレイテストが必要。
- 小さいHPでの範囲砲撃、敵攻撃難度、回復、上級重装の硬さを改めて調整する。
