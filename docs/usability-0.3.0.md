# 操作と見通しの改善 v0.3.0

2026-10-17（日本時間）。0.2.0を監査し、基本ルール・数値・配置を維持したまま、
判断と入力、進行の見え方を改善した。実プレイヤーの楽しさを証明する記録ではない。

## 観測と変更

| 0.2.0で確認したこと | 0.3.0の対応 |
|---|---|
| 攻撃予測が一行のダメージ・反撃値で、残HPを暗算する必要がある | 双方の現在→結果HP、地形守備、撃破・離脱警告を並べて表示 |
| 敵・支援フェーズ内の処理が一括で盤面へ反映される | 各隊の確定状態を順に表示。通常／高速は独立設定として端末保存 |
| 部隊表以外に未行動隊へ順番に移る操作がない | 次の部隊ボタン、Nキー、命令終了ボタンの未行動数、部隊表の行動済表示 |
| PC用のキー操作がない | 矢印、Enter/Space、A/W、Esc、N。命令を開く段階と確定を分ける |
| 射程内対象も地図上の小さい駒から指定する | 攻撃ボタン／Aの再入力で射程内対象を巡回。タップ・フリックも維持 |
| メニューで開始を押すと進行を即時に置き換える | 進行のある戦闘から切り替える場合は確認画面。戻れば元の戦闘を継続 |
| 保存は版一致のみ。metricsやwarnings等の破損は検証が浅い | 0.2.0の安定保存を明示的に引継ぎ、入れ子・状態・占有も検証 |
| 仮のSVGアイコンのみ | 原画からfavicon、Apple touch、192/512px、maskable PNGを書き出し |
| ツールごとの入口と手順が揃っていない | AGENTS.mdを共通契約にしてCLAUDE.mdから読込。開発・検証・同期手順を明文化 |

再試行は章開始時のロスターと難易度を復元する。別戦場の開始を取り消した際の
仮設定が再試行に混ざらないよう修正した。
通常／高速の再生はいずれも同じ同期エンジンを使い、部分フェーズは保存しない。
選択・メニュー・確定・予告表示でカメラや戦場の大きさを変えない。

## 制限と次の確認

Chromiumの画面・タッチ模擬であり、iOS SafariやAndroid実機での検証は未実施。
ホーム画面への追加とOSのアイコン切り抜きも実機で確認が必要。
横持ちの砲撃予告があると予測欄が小さくなり、欄内のスクロールが必要な場合がある。
画面外の敵行動は記録に頼る部分が残る。勝手なカメラ移動を避けながら、結果の見せ方を改善する。
第2章の本陣防衛・別働隊の初見難度やP3攻撃の有用性は引き続き検証課題。
数値や新しいルールで解決したとは扱わない。次の順序は [ROADMAP.md](ROADMAP.md)。
