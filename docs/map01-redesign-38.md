# マップ01の比較試作（Issue #38、第1段階）

目的は、初心者が立て直せる短い交戦をつなぎ、進路・出撃兵種・攻撃順で速度差が出る入口にすること。全6マップ改修のうち、今回は01と比較基盤（#41）を実装した。02〜06の地形・配置は変えていない。

## 方針と互換性

- 12×20、出撃城(5,16)、北城(6,1)、敵ID6隊、HP6・P1→P4・出撃・P3・01〜03連戦を保持（座標は0始まり）。
- 西の渡し(2〜3,10〜11)と街道を追加。中央・東の旧橋は残す。敵は動かない守備にして射程と交戦順を読みやすくし、西の盾・中央の弓と剣・東奥の魔術師で進路の利害を作る。
- 新しい通行不可マスは追加しない。旧版で合法だった全通行マス、部隊・警告の座標を維持。途中保存はHP・位置・turnを保持し、地形の正本だけを現行に置き換える既存の読込規則を使う。保存形式・キーは不変。
- 誘導は既存ブリーフィングだけ。新しい強制説明、数値、AI規則、UI、音源、物語イベントは追加しない。
- 旧地形・敵の全体をfixtureに残し、新しい正確な期待値は別fixtureにする。旧ルート契約のテストは明示的な旧遭遇fixtureで保持。移動observer検査は、静止守備になった01にも移動する敵を明示的に配置して検査を続ける。

## 同じ方策による比較

難易度は標準、classic、初ターン2隊/以後1隊、35ターン上限。[全観測値](tactical-report-38-41.json)、[定義と再現方法](tactical-observation-41.md)。ターン上限で未決着の場合の表示はT36となる。

| 方策 | 改修前 | 改修後 | 改修後の命令/離脱/無交戦turn |
|---|---|---|---|
| 標準前進 | 未決着・離脱6 | T7勝利 | 26 / 1 / 0 |
| 3ターンごとに待機 | 未決着・離脱7 | T10勝利 | 40 / 1 / 1 |
| 騎兵先行 | T16敗北 | T7勝利 | 27 / 0 / 2 |
| 攻撃兵種優先・P3なし | T13勝利・45命令 | T6勝利 | 22 / 0 / 0 |
| T2に寄り道 | 未決着 | T8勝利 | 30 / 0 / 2 |
| 西の渡しを指定 | 旧地形では経路未成立・停滞 | T9勝利 | 36 / 0 / 1 |
| 中央の橋を指定 | 未決着 | T7勝利 | 27 / 1 / 0 |

標準前進の初ターン敵攻撃は2→1。攻撃兵種を優先すると標準前進より1ターン・4命令短縮でき、中央突破は西回りより2ターン・9命令短い代わりに離脱が出た。騎兵先行が最速にはならなかった点も残す。これは再現可能な方策の比較で、人間の楽しさ・最適解・全初心者の無犠牲攻略を証明していない。

## 残件と試遊

- 01：西回りの安全性が自然に読めるか。中央の弓の射程に気づき、盾で受ける/弓から処理する判断ができるか。静止守備が受け身すぎないか。
- 味方をT2に遠回りさせる、P3を使わず攻撃兵種を続ける、3ターンに一度待つ進め方を実際のタッチ操作で比較する。
- 同じ戦場を基本攻撃で進めた時のテンポ、スクロール量、誤操作、永久ロストの納得感はiPhone Safariで未検証。
- 01の試遊後に02〜03の本陣/砲撃、04〜06の長距離・雨・出撃隊列へ展開。現行02の早期陥落、03/04/06の停滞は改善済みとしない。
- #37のT1二隊セーブ修正は独立PR #46。入力PR #36、演出PR #45、物語方針PR #44との全体調整は15時のClaude昼ランに任せる。
