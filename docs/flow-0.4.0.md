# 連続スライド・直接命令・移動と戦闘の演出 v0.4.0

2026-10-17（日本時間）。0.3.0の命令／確定の段階を整理し、入力から行動までのテンポを改善した。
4フェーズ・兵種・数値・地形・敵AIの判断は維持。実際の人間の楽しさや実機での押しやすさを証明する記録ではない。

## 操作

1. 未選択の青い部隊を押す。その指を離さずスライドすると、地形コストに沿う矢印が伸びる。
2. 空きマスで離すと「攻撃・待機・戻る」の小さい半透明ウィンドウ。
3. 敵マスまで続けて滑らせると、最後の合法な射撃位置を保って敵を指定し、予測とメニューを表示。
   指のイベントが途中のマスを飛ばした場合も、到達可能な攻撃位置を選ぶ。
   指を空きマスへ戻せば経路編集を続けられる。
4. 指が残っている間はプレビューのみで命令を実行しない。離した後、「攻撃」または「待機」を一度押すと実行。別の命令／確定ボタンはない。
   攻撃不可なら攻撃を無効化。複数の対象がいる場合は↻で予測を切り替える。
5. 「戻る」、pointercancel、複数指は行動・回数を消費しない。移動範囲外で離した場合も誤実行しない。

その場での行動は部隊をタップして3択を出す。空き場所・青範囲外からのドラッグは独自の地図パン。
経路編集の指を端へ寄せて保持するとマップがスクロールする。これは明示的なカメラ操作として扱う。
通常の選択・メニュー・取消・実行・警告表示では戦場の大きさやスクロールを変えない。

`touch-action:none` を押下前から設定し、pointer capture、非passiveハンドラ、
contextmenu/selectstart/dragstartの抑止、`-webkit-touch-callout:none` を組み合わせる。
2本目の指が地図の外のメニューボタンに触れた場合も、documentの捕捉で先に取り消す。
選択後にtouch-actionを変えるだけの方式に頼らない。ダイアログの文章や設定欄は通常のスクロールを保つ。

## 演出と音

- engineは同期解決のまま。observerへ move / hit / heal / settled を通知する。
- 味方・敵とも隣接した経路マスの間を補間し、軽い上下動で歩行を表示。
- 移動→最初の攻撃→合法な反撃を順次表示。近接は踏み込み、遠隔・回復は光の移動。
  HP・ダメージ・フラッシュ・離脱のフェードもそれぞれの命中時点に反映する。
- 敵は一隊ずつ経路移動と戦闘を終える。支援攻撃には反撃を作らない。
- 通常／高速、OSの「動きを減らす」、背景タブでも同じ最終結果。演出中は命令入力をロック。
- 選択・経路・足音・実行・攻撃・被弾・回復・フェーズの短いオリジナル合成音。
  外部音源や通信は使わない。最初のユーザー操作で音を解禁し、画面上の「音」で永続ミュート。
  音声APIや保存が使えなくてもゲームを止めない。

P1で選んだ命令は、同期解決した**完全な最終状態を演出前に保存**する。
演出中の再読込で移動や確定済み攻撃を失わず、HP変化途中のスナップショットを保存しない。
敵フェーズ途中は引き続き保存しない。0.2.0と0.3.0の安定保存は引継ぎ可能。

通常速度のテストはタイマーで実際の表示状態を採取し、最初の命中後にも攻撃側のHPが減っていない時点、
次の反撃後にHPが減る時点、タイル間の小数座標を確認する。結果だけの比較にしない。
音はAudioContextのrunningと発音のスケジュール、ミュート中の発音0を確認した。
テストブラウザは出音をミュートしているため、人が実際に聞いて音量・音質を評価したという意味ではない。
