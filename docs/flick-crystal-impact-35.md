# Issue #35 — 2ダメージの結晶破砕／攻撃フリック即確定

採用判断：2026-10-21、プロデューサー。基準main `949faf8b340707ccddf89404eb6b92c1ae7cb1d5`。この変更は**実装と自動検証ができるPR**までを扱う。実機の触り心地・音は未検証である。

## 意図
2ダメージはHP6戦闘で何度も聞く**標準攻撃**なので、弱い音を繰り返すより「打撃の芯があり、二つの結晶が明確に割れ、二つ目で着地する」を優先。打撃の瞬間の短い低音とノイズの重量を増し、破砕2回のガラス質と2つ目の余韻を強化。4+の長い大ダメージ専用ヒットストップ／強打低域は残す。音の重なりは第三の「パリン」に聴こえない程度に。重装は鈍い音色が先で、破砕回数は実被害を守る。最大HPや被害計算は不変。

## 操作の受入仕様
| 入力 | 結果 |
|---|---|
| 味方を押し、合法な移動先へドラッグ、そのまま射程内の**敵へ**滑らせて敵上で離す | **攻撃を一度だけ即実行**。200msロック／追加ボタン不要。途中の明示した終点からのみ判定する |
| 経路のプレビューを先に作る→その終点から敵へフリック | **同じく即攻撃**。位置を自動差し替えない |
| 味方を押し、その場射程内の敵までフリック | 元の位置から合法なら即攻撃。勝手な移動はしない |
| 敵を単にタップ | HPと反撃のプレビューのみ。即攻撃はしない。ボタンはアクセシビリティの代替 |
| 敵を通り過ぎ、空きマスで離指／不正な対象へ離指 | **攻撃しない**。狙いを解除し、元の経路を勝手に変更しない |
| 200ms未満で空きマスに離指 | 既存の手動待機／戻る経路を維持 |
| 合法な空きマスで約200ms保持→そこで離指 | 移動＋通常待機を実行。従来の一手Undo対象 |
| `pointercancel`、2本指、画面外、P3専用兵、弓の近接不可 | 攻撃禁止・不正コマンドを消費しない |

### 実装上の安全境界
- フリックが**敵上で終わり**、明示された入口（味方を起点とするドラッグ・選択済み経路・合法な移動先・城の出撃起点）に限り直接確定する。
- `slideDraft`はアンカーなしだと「攻撃できる位置」を自動選択する可能性がある。敵へ入る直前の**実際に見せていた移動先**をアンカーとして固定し、`routeTo`と`inRange`の同じルールで判定。勝手に近寄って撃つ操作にしない。
- フリック中は固定ドックの命令ボタンを表示せず、経路と反撃込み残HPの**ライブ予測**だけを見せる。終了時のタップ/キーボード用ボタンは残す。
- 音・グラフィックは既存`audio.js`、`playback.js`、`render.js`の演出専用変更。戦闘計算、ログ、フェーズ、出撃枠、保存形式、P3専門職化、HP6は不変。

## 検証項目
- `npm run check`：通常1と2の打撃合成音の強さの差、2回の明確な破砕トランジェント、従来のHP6/攻撃・支援・保存テスト。
- `npm run test:browser`：タッチ連続ルート→敵、既存の経路→別フリック敵、0.2秒未満、敵通過後の取消、タップが即攻撃しないこと、P3専用兵、不正弓・保存・一手Undo・城出撃。
- iPhone実機：基本攻撃2を10回／1を3回／3を3回、重装で軽減時を数回。SE OFF/音量/BGM同時再生。敵へフリックを繰り返し、誤発火の有無・連続出撃の速さを体験。ブラウザシミュレーションと実機は区別。

## 対象外とリスク
high（入力確定のタイミング変更）、medium（音・描画）。何も確定していない時の過剰な自動攻撃、タップ操作の廃止、数値変更、mainへの直接pushや自動マージはしない。統合は正本の15時昼ランの役割。CI後も独立監査と人間の試遊を未検証として引き渡す。
