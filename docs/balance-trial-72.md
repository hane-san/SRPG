# Issue #72：兵種が戦場の意味を変えるか — 小規模バランス試作

> 試作PR。採用済みは「整理された基本兵種で細かなバランスを検証する」方針であり、個別マップの変更は比較と試遊後に採否を判断する。主眼は戦術的な違いと操作テンポ。HP6やP1〜P4のルールの再設計はしない。

## 実際に変えたところ

| マップ | 変更前 | この試作 | ねらい |
| --- | --- | --- | --- |
| 01 霧河の渡し | 橋手前(4,12)の正規軽装兵 `e1`、攻撃2/HP6、hold | **賊**、攻撃1/HP6、hold。位置・ID・人数不変 | 初めての渡河交戦を軽くし、進軍のリズムを作る |
| 04 長河の三橋 | 追加味方 `aux-shield`「後衛槍隊」が重装兵、軽減1 | **槍兵**、軽減0・対騎兵+1。HP6/攻撃2/移動4、IDと予備人数不変 | 橋際の防衛線で、盾で受けるか槍で騎兵を牽制するか考えさせる |

その他の既存マップ（02、03、05、06）の兵種/敵ID/地形/配置/AIと現行9人・回復3枠・騎兵2枠は維持。01と04でも敵人数・拠点・地形・P4予告は維持。**賊が1ダメージでも最低1保証があるため、重装相手は弱いが無力ではない。** 槍兵は万能の戦線突破役ではなく、重装の被ダメージ軽減を放棄した対騎兵特化役。

## 比較実験の判断基準
1. 01：初心者の初遭遇が軽くなり、雑な操作でも進める。速攻策に目立った手詰まりや追加ターンが出ない。かつ賊1体のHP6を削る交戦自体は残る。
2. 04：槍兵は騎兵に3ダメージ、普通の歩兵に2ダメージ。重装との被ダメージ差が分かる。橋に籠るだけでも騎兵突進だけでも一方的に最適にならない。
3. 両変更とも既存の攻防・全滅/永久ロスト・出撃枠/P3専門支援・城・保存キーや旧v0.8途中戦闘を壊さない。
4. `npm run check`、`npm run test:browser`、`npm run simulate`の既存期待値を**緩めず**比較。既存の政策シミュレータは最適解ではない。失敗した候補はPRに記録し、リスクの大きい部分だけロールバックする。
