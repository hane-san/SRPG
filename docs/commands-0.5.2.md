# v0.5.2 — 盤面外の命令欄と水色の攻撃域

## 変更の理由と範囲

移動先の近くに窓を出す方式では、青い移動域とその外側の攻撃域が画面いっぱいに広がると、別の有効マスを遮っていた。文字の多い二列の戦闘予測も小画面では読みづらかった。

- `index.html` / `style.css`：命令を地図とは別の高さ固定欄に移動。命令欄の表示・非表示で地図を伸縮させない。予測・操作は14px、ボタンは44px以上。
- `app.js`：経路編集中・指を保持中は命令を隠す。部隊名・兵種・HPと短い予測、攻撃・待機・戻る・詳細に絞る。複数対象時のみ対象切替を追加。能力や支援候補・温存設定は詳細へ。
- `render.js`：味方の通常攻撃可能域を水色、その外周を水色の発光へ変更。移動は青で白青の縁。敵の危険域やイベント予告の意味は維持。
- `save.js` と版管理：0.2.0〜0.5.1の安定保存を0.5.2へ引き継ぐ。戦闘・天候・射程・ダメージの計算は変更なし。

## 再現・検証

`npm run check`（44件）、ローカルHTTPサーバーで `npm run test:browser`。

- 全6マップ×4画面（390×844、360×740、320×568、844×390）：直接命令、4ターンの進行、保存復元、地図の位置保持。
- 命令欄：上記と1363×936、各予告あり／なしの10条件。移動中は非表示、解放時に表示。盤面との矩形の交差なし、ボタン44px以上、予測14px以上、横はみ出しなし。
- 320px幅の複数対象：5ボタンと離脱警告・弓の注意を表示し、対象を切替。敵の方針を詳細で確認。敵・行動済み選択時の表示更新も修正。
- 実タッチ入力：未選択部隊からスライド、敵上で保持、二本指・中断、長押し、パン、端スクロール、二重実行防止。
- 描いた経路を敵への二度目のフリックでも維持し、その終点から攻撃。射程外は経路を維持して攻撃不可。P3全員回復・シューター・雨・弓の飛翔も継続確認。

## 制限・本人確認

Chromiumのタッチ模擬であり、iPhone Safari／Android実機での指の感触や音の聴感を保証するものではない。実機では読みやすさと盤面の広さのバランスを確認する。命令欄の開閉による地図の揺れを防ぐため、未選択時にも同じ高さを確保する。端末に旧版が残る場合は再読込する。本人による設定・再インストールは不要。
