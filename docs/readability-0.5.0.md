## 実装
- 常設の下部案内を除き、「表示」でズーム・危険域などを開閉。盤面を変形・自動スクロールさせず、半透明の命令窓の位置を選択元・移動先・攻撃対象から選ぶ。極端な画面・配置で全てを避けられることまでは保証しない。
- 兵種を大盾、剣、弓、魔法帽、杖、救護鞄、馬、車輪付き射撃器と漢字記号で区別。マップごとに霧・乾地・灰城・青い長河・雨の森・暁の色調。
- 通常速度は移動130ms/タイル、行動開始280ms、射撃320ms、命中380msなどの読み取り時間。敵は一隊ずつ、攻撃と反撃は別に表示。高速・音OFFは保存可能。
- 弓は通常2、静止待機のP3は2〜3、隣接不可。矢の向き・飛翔と魔法を区別し、射撃・斬撃・魔法・命中音を描き分ける。合成音に外部音源・通信は不要。
- 祈祷・救護のP3は上下左右の隣接味方全員に各7回復。自分、敵、斜め、満HPは対象外。何人でも1ターンの発動で1回だけ消費。最後の1回でも全員+7。無対象は消費0。枯渇後は既存H1/H0/H2を各対象に適用。旧「欠損4以上」の条件を廃止。
- 新規戦闘の基本編成にシューター「ニコ」を追加。HP10、攻9、守1、移3、通常射程2〜3、残2回。動かず待機したP3に距離1〜5の敵全員へ1発ずつ、反撃なし。1ターンの範囲射撃で1消費、無対象・温存・移動待機は消費0。
- 追加戦場04「長河の三橋」12×40（味方11・敵13）、05「森壁の回廊」16×36（11・13）、06「暁の城塞線」14×44（13・15）。単体選択用。連戦は既存の第1〜3章。
- 05はT1雨なし、T2雨なし、T3小雨、T4大雨、T5小雨、T6〜7雨なし…の5ターン周期。P4を越えて翌ターンの移動へ適用。小雨は歩兵−2/騎兵−3、大雨は−3/−4、すべて最小1。敵味方・経路・青範囲・危険域・敵AI・詳細表示は同じ移動計算を使う。森の地形コスト2は別に残る。

## 保存とバランス
安定した0.2/0.3/0.4の保存を継続でき、保存済みの部隊・HP・行動を維持する。既存保存にシューターを途中で自動追加しない。新規開始・次章・再試行時の編成には追加される。回復ルールは更新後のP3に適用。敵フェーズ途中の保存は禁止、P1は演出前に確定済み最終状態を保存する。

回復・シューターの導入で攻略結果は変化する。旧版とのシミュレーション完全一致は今回の合格条件ではない。貪欲な自動方策の勝敗は人間の面白さやクリア可能性の証明ではない。追加マップと全体支援の強さは今後調整する試作値。
