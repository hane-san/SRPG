# 矢印の終点・移動先ポップアップ・範囲表示 v0.5.1

2026-10-18（日本時間）。v0.5.0からの操作・描画・音の改善。戦闘数値、雨、P3の回復・シューターは変更しない。

## 操作の修正

原因は、敵へフリックする途中の空きマスによる移動先更新と、射程外の敵に対する別の接近位置の自動探索。明示的な矢印があるときは、その終点と経路を攻撃の基準として保持する。

- 一度描いた矢印からの追加フリックは、途中で別の空きマスを通っても終点を変えない。元のユニットからフリックし直す場合も保持。
- 終点から届かない敵は「射程外」と表示し、攻撃を無効にする。別の地点や別の敵へ勝手に切り替えない。
- 移動先を選び直す場合は空きマスで離す。別の味方を押せば通常の部隊選択。
- まだ明示的な経路がない状態で敵を直接指定する従来の接近提案は維持。
- 指を離すまではプレビュー。攻撃・待機で実行し、取消・複数指では消費しない。

## 表示と音

攻撃・待機・戻るの窓を移動先の近くに配置し、指示矢印を添える。移動先・移動元・敵に重ならない候補を優先し、端では画面内へ収める。盤面のサイズ・スクロールは変えない。極端な画面や密集時には完全な重複回避を保証しないため、窓の半透明は維持する。

移動範囲は一定の青と明るい外周。元の地形と森・道・砦の小さな地形印を残す。通常攻撃が届く範囲は、合法な移動先それぞれから算出した青の外側の赤い領域と発光外周。青と赤は重ねず、味方の占有マスを赤くしない。P3の範囲とは区別する。既存作品の画像・音は使用しない。

音は短い高域ノイズ、低い打撃音、金属的な倍音を重ね、余韻を短くした。外部音源・ネットワーク不要。音OFF・ユーザー操作後の解禁・音声APIがなくても進行する仕組みを維持。

## 変更箇所

- `ui-model.js`：明示的な終点の保持、射程外の結果、移動／攻撃可能域の導出。
- `app.js`：二度目のジェスチャーの終点固定、射程外表示、移動先基準の窓配置。
- `render.js` / `style.css`：青と赤の範囲、外周、地形印、指示矢印付きの小型窓。
- `audio.js`：短いノイズと打撃・金属音。
- `save.js` とリリース参照：0.2〜0.5.0の安定保存を引き継ぐv0.5.1。
- `tests/flow.test.js` / `tests/destination-check.mjs`：再現と回帰検証。
