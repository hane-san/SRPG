# Issue #28 — HP6宝石演出・実装記録／試遊ポイント

2026-10-21、プロデューサー採用の方向性。基準main `8c409c6273b874dffd7e49e49eb8ec3bdabd61aa`（v0.8.0）。本PRは**表示／音の試作のみ**。テストとプレイヤーの体感は区別し、main統合は承認後。

## 設計判断：6個の生命結晶
- **1点 = 宝石1粒。** 1〜3は攻撃の衝撃音の後、74ms間隔の同系統「パリン」。1/2/3の音の数が実HPの減りと一致する。
- **4以上は別格。** 打撃音の低域とアタックを厚くし、約66msのヒットストップ→49ms間隔で高速破砕。攻撃5でもHP残2なら砕ける粒は2。攻撃自体の強さは音で伝える。
- **重装兵**：防御値やガード技能で軽減しているときは、初撃を鈍くし、破砕音もわずかに低音化。ただし失うHPと粒数は最終ダメージによる。専用の鎧破壊リソース等は追加しない。
- **敵の撃破**：最後の粒とともに、駒が小さな結晶片へ崩れる。味方の永久離脱も視覚的な言語は同じで、低く消える余韻だけを変える（勝利ファンファーレを誤用しない）。
- **回復**：実回復した粒数だけひとつずつ結晶が再生。HP6を越えない。
- **音源**：既存サウンドのコピーをせず、`audio.js`のWeb Audioからオリジナル合成。SE OFF/ブラウザの制限で無音でも戦闘を妨げない。

## アニメ・エンジンの境界
エンジンの`hit`/`heal`イベントと`state`は一切変更しない。`gem-effects.js`は`before.hp`・`after.hp`・実イベント`amount`から**演出専用の数とスケジュール**を決定する。`playback.js`はすでに同期解決してP1に保存した最終結果を変えず、表示中のHP6ピップだけ段階表示する。ドックの戦闘結果は同じ段階に追従する。終端で正式な`state`に切り替える。

- 途中ブラウザ背景化 → `tween(0)`で直ちに最後へ。演出音は`audio.js`側で停止／再生不可扱い。
- 高速・reduce motion → HPピップは正しい数だけ更新、ヒットストップなし・各ステップ短縮。カメラ移動や追加のマップ全面サーフェス生成は不要。
- `finally` の既存`commit()`復旧フローを温存し、描画途中例外でも最終状態／入力ロックの復帰へ。
- 音はWebAudioで先行スケジュールし、低FPSでも音が連続して聞こえる。各ジュエルの時間軸は演出で一元化する。
- 倒された駒は、最後のHPピップが砕けるまでは表示上のユニットとして残し、HP0に達した後のみに結晶片の崩壊へ。敵P2の連続演出や合法な反撃が演出により追加されることはない。

## 体験できる方法
**ゲームメニュー → 「💎 宝石の破砕音を試す」**。HP6の模擬結晶で以下を比較。4/5の敵や強い攻撃が本編にまだなくても、シミュレーターだけで試聴できる。試聴は本編のコマンド消費・HP・セーブに干渉しない。

1点、2点、3点、4点（強打）、5点（強打）、攻撃3→重装の軽減で被害2、HP2の敵を撃破、HP2の味方が戦死、2点回復。
