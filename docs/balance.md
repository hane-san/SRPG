# 仕様・バランス検討 v0.1.0

2026-10-17（日本時間）。引継ぎv0.3とWork起動プロンプトの全文を読んだうえでの実装。数値は試験仮説であり完成バランスではない。

## 優先した体験

目的は、前進・停止・分散・護衛・火力の先払いを選びたくなること。マス目や資源の種類を増やさず、同じ8隊・同じ戦闘計算を3マップで使う。

## 批判的に変更した点

| 問題 | 仮採用した処理 | 理由・反証条件 |
|---|---|---|
| 待機中の通常反撃とP3射撃の二重取り | 待機支援時はP2反撃なし、P3射撃にも反撃なし | 構えると安全になるだけの支配戦略を避ける。支援が選ばれなさすぎるなら射程・配置から直す |
| 盾の「通過阻止」は敵AI・危険範囲の説明まで増やす | 通常守備−1、堅守−3の数値差のみ | 隘路・森・砦で壁を作る価値を先に試す |
| 騎兵の敵通過は移動阻止との例外を作る | 疾駆＝移動+2、通常の通行条件は共通 | 分岐路の機動力だけで十分な択が生まれるか先に試す |
| 即時回復と待機回復を1隊にまとめると枠競合が見えない | 祈祷隊と救護隊を別隊として同じ編成へ | 同じ戦闘で停止のコストと即時救命を比較できる |
| 永久離脱を単発マップだけで検証できない | 単体試験＋3章連戦、離脱継承と最低4隊への補充 | 単体再試行は巻き戻しという試験操作。連戦の次章では名前付き離脱者は戻らない |
| 安全な戦場では有限回数だけで停滞を防げない | 基準の第1はイベントなし、第2は本陣と南増援、第3は予告砲撃と有限増援 | すべてに厳しいターン制限を加えず、マップによる差を測る |
| 特殊守備を使っただけで回数が減る | 被攻撃が実際に起きた時のみ消費 | 対象なし・効果なしでは資源が減らないという契約を統一 |

## 自動プレイで実際に直した箇所

初期配置の第2・第3は、4ターンごとに3隊の増援だった。単純な前進・慎重策がどちらも押し潰され、「新手が来る前に全軍で突破する」圧力が過大だった。第2を1隊ずつ、第3をT4/T8各2隊へ減らした。変更前の再現結果は `simulation-before.json`、調整後は `simulation-results.json`。

敵襲撃隊が本陣まで届くのに別の攻撃を選ぶ不自然さも修正。本陣に入れる場合は占領を優先する。増援地点の占有は、そこでの到着を中止する明示ルールとした。

## 調整後の観測

簡易方策はその時点の攻撃・回復・距離・保守的な危険値を評価する貪欲なエージェント。最適解の探索ではない。「全待機」は初期位置から待機・守備だけ。「慎重」は最大被害への罰点を大きくする。同じ試験を `npm run simulate` で再現できる。

| 試験 | 通常前進 | 慎重な前進 | 初期位置で全待機 |
|---|---|---|---|
| 第1 | T10勝利・8隊生存 | T16勝利・8隊生存 | T36打切り・4隊生存、未クリア |
| 第2 | T3本陣陥落・6隊生存 | T16勝利・7隊生存 | T3本陣陥落・6隊生存 |
| 第3 | T21勝利・5隊生存 | T36打切り・2隊生存 | T12全滅 |

第2は全軍前進では本陣を失う。第3は慎重に固まりすぎると砲撃・増援で崩れる。第1に対し他2マップで判断を変える必要があることは確認した。ただし**人間の楽しさや、攻略法の優劣を証明する試験ではない**。

東回り・南城先制の貪欲方策はどちらも本陣を失い敗北。南城制圧自体は成功するが、留守番の編成・本陣占有・交代が足りない。経路としては通行可能でも、初心者向けの別解としての成立は未確認。次の人間テストで最優先に見る。

## 残る問題と次の順番

1. **待機射撃が少ない。** 調整後の通常前進は第1で支援1回、第3で3回（回復を含む）。攻める価値はあるが、P3射撃を使う拠点の配置や敵の進路をもう少し作る余地がある。即座に敵P3スキルや新状態を足さない。
2. **東回り・南城攻略の留守番が難しい。** 第2の標準難度が初見で厳しい可能性。まず練習の敵攻撃−2、南の開始位置、増援T4の時期を比較する。北攻略の支配的な一本化は避けたい。
3. **H1は待ち時間を完全には消せない。** HP半分までは無限に戻せるし、1ダメージと1回復が均衡する耐久もある。H0との差は満タン回復稼ぎの抑制に限られる。時間圧力がない第1では停滞が残りうる。経験値・報酬稼ぎは未実装。
4. **危険予測は安全側すぎる。** 守備AIの3マス制限と敵同士の通行競合を省くため、実際には集中しない被害も合算する。正確な敵未来予言と誤認させず、数値の説明は残す。
5. **通常反撃に回数上限がない。** 強い前衛の反撃回数が多数になると、敵が多いほど反撃で倒せる問題がある。まず敵数・攻撃射程・地形で見る。反撃専用資源は増やさない。
6. **予備隊の救済は最低限。** 4隊を保証してもノーロスト攻略を保証しない。連戦の個別難度調整・編成画面・章間物語はまだない。
7. **仮グラフィックと地図操作。** コードで描くオリジナルの小部隊。最大広域マップは小さなマスになるので倍率ボタンで補う。常時の格子は消し、移動範囲だけ強調。iPhoneでの押し間違い頻度は今後測る。

保留：乱数命中・必殺、移動1マス＋P3、通過阻止、属性相性、成長、装備、経験値、音・会話。仮説が成立するまで足さない。
