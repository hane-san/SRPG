# Issue #48: 武器の勢いで「戦い」を感じる / ボスの最後の結晶

## 方向性（2026-10-22 採用）
プロデューサー判断：攻撃はちまちま削るだけに見せない。「打撃の勢い→HPジュエルが実ダメージ分だけ割れる→敵が打ち負ける」アニメへ。SEとアクションが気持ちよく一体になることを優先。前のエフェクトPR #45の上に積む。**あくまでゲーム内視覚表現であり、宝石が世界観の物理的生命体という設定は未確定。**

## 実装・試遊の対照表
| 兵種・局面 | 具体的な動き | ねらい |
|---|---|---|
| 剣 | 前へ短く踏み込み、標的に太い曲線の剣閃 | 通常攻撃2でも軽い数値の削りに感じさせない |
| 盾槍 | 胴体の重い前進、斜めの幅広い打ち込み | 防御時の真鍮火花と見分ける |
| 騎兵 | 突き抜ける直線軌跡、低く速い風切り音 | 突進の気持ちよさ。移動距離による攻撃ボーナスなし |
| 弓 | 既存矢の動きに沿う明瞭な尾 | 遠距離でも着弾が先に見えない |
| 砲撃／魔術 | 弾芯の太い残光／魔力の軌跡 | P3砲撃、敵術兵を視覚的に区別 |
| 普通の敵撃破 | HP0で8粒の通常破砕 | 既存の「最後の結晶」言語を維持 |
| ボス撃破 | 敵ID `boss` のHP0のときだけ、最後の結晶に放射状の亀裂＋大きい12粒破砕と重い余韻 | 主要な撃破の達成感。HP・回数・勝利条件は不変 |

## 受入条件
- [ ] 攻撃準備`windup`の**既存200ms/弓320msの中だけ**で、軌跡と踏み込みを再生（新たな待ち時間0）。`weapon-fx.js`は演出型・時間包絡だけを決める純粋関数。P1/P2/反撃/P3砲撃も共通のプレイバックを通す。
- [ ] HP数値は`engine.js`が決定。2なら2回の`gem-chain`、4+なら既存のhit-stop、オーバーキルは実HPのみ破砕。ボス演出は`id==='boss' && team==='enemy' && lethal`のみ。
- [ ] ボスを倒しても別のHPバー、追加行動、ボーナスダメージは発生しない。名前のある一般敵、味方の戦死、援軍の死亡を特別扱いしない。
- [ ] fast/reduced motion/非表示の時は追加軌跡と被弾揺れを抑える。SE OFFでもコマンド完了。144pxドック・カメラ・フリックの入力状態を変更しない。
- [ ] 線・破片は既存canvasのみ。terrain/board/range cachesは演出フレームで再生成されない。ブランチ内`package.json`へNode/ブラウザ検証を追加。
- [ ] 実機試遊：同じ2ダメージの剣／盾／騎兵を交互に試す。弓や砲撃は「発射→飛翔→ヒット」へ違和感がないか。ボスの亀裂はスマホ画面でも判別できるか、敵フェーズが長すぎないか。
