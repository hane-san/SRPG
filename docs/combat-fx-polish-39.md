# Issue #39：戦場の小さな反応を統一する（方向性／第1弾PR）

## 採用された方向性
プロデューサーの2026-10-22夜間指示。「宝石を破り合う」感触を戦闘・移動・回復へ広げ、既存の操作テンポを守りながらアップグレードする。今回は**最小・高頻度の反応**を改善。HP6、兵種の戦闘性能、P1→P4、P3特化、保存仕様は不変。

## 今回の実装案（小さな効果に絞る）
1. 初撃・結晶破砕：**受けた駒だけ0.75〜2pxのごく短いノックバック**、その周囲に一瞬の衝撃リングと小さな放射線。1点は控えめ、2点は標準攻撃として明確、4+は既存hit-stopを一番重く感じさせる（停止時間の追加なし）。`feedbackStyle`が寸法と濃度を決定し、`impactFrame`は0〜1へ収束する。
2. 重装：通常より小さい円＋真鍮色の太い短線。**防いだHP数に応じて何かが砕けたと誤認させない**。実被害によるパリンと重ねる。
3. 回復：緑の光輪と柔らかな放射線で、砕く音/火花と区別。実回復だけが結晶になる。
4. 移動：各タイル最後の30%の歩行補間中、接地点左右に淡い粉塵。65ms/1歩の既存時間の内部のみ、時間追加ゼロ。
5. 早送り・動き低減：被弾ノックバックと着地粉塵は無効、その他は既存の短縮タイミング。画面全体のシェイク、ポストエフェクト、canvas追加、DOM改造なし。

## 対象外・保留／追加提案
- **対象外**：現状の4+に別の必殺判定を作る、SEを大量追加する、マップ全面に雪/天候粒子を常時描く、カメラシェイク、着地で新たに毎マス待たせる、SE/BGM個別音量UI。派手さとテンポ/戦術読みやすさのバランスを試遊で見てから判断。
- **提案（未採用）**：マップ別天候効果音、騎兵だけの足音、特定ボスの宝石エフェクトの個性、最後のジュエルにごく短い特別な沈黙。今回一括実装しない。
