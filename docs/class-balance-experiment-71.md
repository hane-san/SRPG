# 7兵種整理後・第一段階バランス試作（Issue #71）

2026-10-24。[`#68`](https://github.com/hane-san/SRPG-01-FEstyle/issues/68)の7味方兵種＋敵専用の賊（旧回復2種は魔術師に統合）を前提に、**敵2隊の種類だけ**を変える比較試験。新ルール追加ではなく、#38の01初心者向け・06三段攻勢を崩さず、賊と槍の区別が見えるかを調べる。

HP6／近接2／重装軽減1／槍対騎兵+1／賊の攻撃1、味方9人中3魔術師・2騎兵、T1最大2隊・以後1隊出撃、盤面5隊上限、P1〜P4、P3静止魔術師治療/砲兵、南城と予告イベント、01〜03連戦は維持。旧`healer`/`medic`保存データの移行は#68で実装済み。新しい保存キー/スキーマや全隊再配置は行わない。

## この小さな実験で変えること
- **01「霧河の渡し」**：本城に近い先触れ`e1`を「軽装兵（攻撃2）」から**敵専用の賊（攻撃1）**へ。同じHP6、同じ初期位置(4,12)、同じ`hold`、同じ敵ID。最初に通常の2ダメージで結晶を割る学習や初見立て直しを邪魔しない。
- **06「暁の城塞線」**：南側の河付近の敵`extra-5-0-2`を「軽装兵（通常2）」から**槍兵（通常2、騎兵へのみ+1）**へ。同じ座標(2,26)、同じ`defend`、同じID。騎兵だけで南河の端から突っ切るリスクに意味を持たせる。ブリーフィングの該当兵種だけ修正。
- 両者とも **全地形、敵の総数、敵ID、敵の位置/AI、敵将、城、砲撃/増援、味方編成/BGM/SE、HP/防御/移動の全体定義は維持**。06の南城制圧という代替戦略も残す。

## やめた案と理由
- テオ（旧救護職）を槍に変更：#68実験時に02〜06などが崩れた。3魔術師の治療担当は守る。
- 追加戦場06の味方補助`aux-shield`を槍へ：参考`advance`はT31勝利/離脱9→35ターン未決着/離脱11。重装の被害軽減と出撃順の価値が強く、全員を槍へ置換するのは不適切。
- 追加戦場05の補助重装を槍へ：雨を意識した方策でT17/離脱1→T18/離脱2。豪雨時の森コスト2と移動1の組合せも悪い。
- 02の序盤剣士を賊に単純置換：従来T11勝利の標準方策がT35未決着になる。弱い敵を入れれば必ず簡単になるとは限らない。
- 04の先触れ剣士を賊へ：通常前進がT18→T21、慎重方策がT27勝利→35ターン未決着。橋渡りの流れに影響する。
- その他の配置候補は本PRへ混ぜない。6マップ一斉変更では原因が読めなくなる。

## 回帰テスト
`tests/class-balance-71.test.js` が、新旧マップをin-memoryで再現して決定論的に比較：
1. 味方9枠・魔術師3・騎兵2を維持、01と06の敵種別以外の地形/城/敵IDを保つ。
2. 賊攻撃1、槍攻撃2・騎兵へ3・重装へ1と、プレイヤーへの予測表示に使う`prediction`が一致。
3. 01の標準/待機/高速進軍が全て勝利。06の標準/南城/前線の3方策に勝ち筋が残る。
4. 旧v0.8途中セーブで、`s.units`の元敵の種類・位置・HPを復元し、`map`の新ルールを適用。保存キーは不変。

PR作成後に`rules`/`browser`が最新headで成功したかを確認する。自動テストの他に`npm run simulate`の全6マップ結果、古い全編成のクラシック3章連戦、難度別は継続検証項目。iPhone実機の触感・効果音・難度は未検証。
