# Issue #24 — スマホ高速入力／一手Undo 技術設計・試遊ガイド

基準：2026-10-21 の main `8c409c6273b874dffd7e49e49eb8ec3bdabd61aa`、v0.8.0。根拠：[Issue #24](https://github.com/hane-san/SRPG-01-FEstyle/issues/24)。**この資料はPR実装案の説明であり、mainへの採用・実機検証完了を意味しない。**

## 目的と分類
- **採用された目的**：短い移動・攻撃入力、200msの「カチャッ」と軽い光、攻撃対象までの連続指操作、移動だけの一手Undo、HP/移動範囲の読みやすさ。
- **本PRの実装上の選択**：移動先で200msの滞在によってロック。ロック以後は終点を固定する。合法な敵で離指なら即攻撃、ロックした移動先で離指なら通常待機。ロック後に別の空きマスで離指すれば取消。範囲外／キャンセル／複数指は非確定。
- **保留して維持**：短い（ロック前の）スライドでは既存の命令プレビューが出る。空きマス2タップによる移動＋待機、キーボード命令も代替操作として残す。「通常タップ移動を全面廃止してもよい」は最終採否が未確定であり今回のPRでは行わない。短いスライドに追加確認が残ることは意図したフォールバック。
- **対象外**：戦闘数値、敵AI、P3、地形／雨の移動コスト、マップ、BGM、キャンペーン／保存スキーマ、任意の過去行動のUndo。

## 入力状態遷移（P1、戦場操作）

| 状態・入力 | 結果 | P1消費 |
|---|---|---|
| 未行動味方の押下→合法な空きマスへドラッグ | エンジンの経路をプレビュー。**最後の合法マスに入るごと**に滞在計時を開始 | なし |
| 同じ合法マスに約200ms | そのマスでロック。短いSE（ミュートなら無音）＋タイルの小さな発光。指は保持し続ける | なし |
| ロック後、元の移動先で離指 | `E.act(...,'wait')`：移動＋通常待機で一回だけ確定 | 1 |
| ロック後、明示移動先から射程内の敵まで滑らせて離指 | 保持中に予測HPと反撃を表示。離指と同時に`E.act(...,'attack',targetId)`を一度だけ実行（追加の攻撃ボタンなし） | 1 |
| ロック後、別の空きマス・合法でない敵・盤外で離指 | 移動先を勝手に変更せず、取消／既存の射程外説明へフォールバック | なし |
| 200ms未満で離指 | 元の攻撃／待機／戻るメニューで手動選択可能。自動実行はしない | なし |
| `pointercancel`、別の指、画面移動中断 | タイマー破棄、元のドラフトを丸ごと復元 | なし |

ロックはタッチ入力の連続操作に加える「高速経路」であり、`engine.reachable`・`routeTo`・`act`・`prediction`以外の判定を実装しない。**ロック後に敵へ向かう途中で空きマスを通っても、出撃位置／攻撃位置は変わらない。** 別の移動先を指定し直す場合はいったん離してプレビューを戻すか、次の操作で指定する。

## Undoの正しさ
`commit('wait')`成功、既存の非出撃味方が実際に動いた場合に限り、直前の**完全なP1状態**を一回分だけRAM上に保持。攻撃・反撃・支援・静止待機・出撃・帰還には適用しない。Undoを押すと座標だけでなく`acted`、`command`、`metrics.commands`、`log`なども戻し、`writeSave`で安定状態を上書きする。

- 表示：高さ144pxの命令ドックとは独立し、盤面の右下に半透明・48pxの `↶` を置く。
- 有効期限：次の**成功した**行動（攻撃・待機・帰還）、ターン進行、支援優先設定の変更、新規開始／再試行まで。部隊の選択・視点変更・予測確認では失効しない。
- 非保存：Undo権利はリロード後に復活しない。**ゲーム本体のUndo後状態は保存する**。アニメーション中は無効化。
- この設計では次の行動結果を見て、二手前の一手を巻き戻すことはできない。

## 見た目
- 青＝`reachable`の合法終点。旧来常時表示していた外側の水色は、選択した敵がいるときだけ補助表示（移動可能と誤認させない）。
- 戦闘時は自HP／敵HPを対称の3行グリッド（現在→後、バー、反撃／攻撃）にし、320pxでも列高を揃える。HPバーの値は行動後。
- 移動候補はドック外の盤面内の矢印と、**既存の高さ固定ドック内**の文字で表示。反撃があるときは指を離す前にHP予測を読む。ドックのサイズ・盤面座標は一切変更しない。
