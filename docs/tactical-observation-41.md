# 戦場の観測と将来の戦果候補（Issue #41）

目的は、配置の前後を同じルール・方策で比較すること。テスト専用のobserverと命令呼出し側で計測し、`engine.js`のルールや保存状態には項目を追加しない。物語方針の集約は別の[PR #44](https://github.com/hane-san/SRPG-01-FEstyle/pull/44)で行う。本書は物語機能を実装した記録ではない。

## 再現

```sh
npm run simulate          # 既存の方策を保持し、01の待機/騎兵先行と02/06の本陣寄り/攻勢寄りも出力
npm run audit:tactical    # 01の変更前後7方策と他5戦場を比較、専用JSONへ保存
npm run audit:issue17     # 歴史的な敵配置比較。地形全体の前後比較とは区別
```

`tactical-report-38-41.json`は基準main `949faf8b` の01をfixtureから復元し、同一HP6・出撃・難易度・敵数6・方策で前後を計測した。実行ソースのSHAは対応PRを参照。旧`simulation-results-*`、`issue17-balance-results.json`は保持した。今回のIssue17結果は別の`issue17-after38-results.json`に置いた。

## 指標の定義と限界

| 指標 | 取得方法 | 解釈の限界 |
|---|---|---|
| 初遭遇・交戦のないターン | `hit` observerが最初に出たturn、hitのない観測turn | 回復だけのターンは無交戦に含む。退屈だったとの判断ではない |
| 前進のないターン | 味方moveの各隣接歩で、空盤面の目標への重み付き距離が一度も減らないturn | 補給・防衛・迂回にも価値がある。失策とは断定しない |
| P1攻撃/待機/出撃 | 成功した明示命令とdeploy observer | `prepareEnemy`が補う未命令待機や、実際のタップ数は数えない |
| P3の有効支援 | P3のhit/heal observer | 待機しただけ、不発、弾薬温存は発動に含めない |
| 初ターンの敵攻撃 | P2・敵actor・反撃でないhit | 単独到達を合算する危険域とは別。実際の方策に対する攻撃数 |
| 北城制圧 | victoryのturn・累計commands | 最短手順や最適戦略の証明ではない |
| 本陣防衛継続/陥落 | baseのある戦場で、敵のbase占有とdefeatを確認 | baseのない06はnull。城付近に部隊を置いた反実仮想的な効用は未計測 |
| 警告からの退避 | P1開始時の着弾予定セルの味方と、P4直前に生存して照準外へ出た味方を照合 | P2で死亡/予備へ戻った部隊を退避成功として数えない。全員の最短到達猶予は未計測 |
| 砲撃・犠牲・生存 | P4のactor=nullのhit、metrics.deaths、最終ユニット状態 | 砲撃hit数は敵味方合計。実HPの減少量や物語上の犠牲価値ではない |
| 使用した橋 | 味方move.pathで通った`+`セルを収集 | 道路指定だけで別ルートを通ったと断定しない |

観測値は`result.tactical`、turnごとの詳細は`play(...).trace`で取得できる。人間の面白さ、スマホの入力回数、最適戦略、未実装シナリオフラグは`unmeasured`に明示した。

## 方策

- `advance`：従来の前進方策を保持。先頭の予備を出し、目標距離・被害・攻撃機会を評価。
- `pause`：同じ前進策で、出撃後の部隊は3の倍数ターンに待機。
- `fast`：騎兵を先行させ、通常より危険を許容する比較例。これが最速とは主張しない。
- `basic`：攻撃可能な兵種だけを出撃。P3を使わない比較例。
- `detour`：T2の既存部隊を西へ寄り道させ、その後は前進。
- `west`/`central`：01の渡河する列を実際のrouteToで制約。同じ座標制約を前後に適用する。旧01には西橋がないため、旧westの停滞は経路未成立も含む。
- `base`/`offense`：02/06で盾を本陣・出撃城へ寄せる比較と、攻勢を優先する比較。高度な防衛AIではない。

02はbase方策でもT23敗北、offenseはT2本陣陥落。06は両方とも35ターンで未決着。この結果は未改修戦場の課題として残し、勝てたことにはしない。

## 将来の戦果フラグ候補（未採用・未実装）

| 候補 | 将来の定義案・取得元 | 偽陽性と保存上の課題 |
|---|---|---|
| 救援成功 | 対象・期限・保護条件を別途採用してから定義 | 現在は救援対象/判定がなく、通常の味方生存で代用できない |
| 砦の確保 | 指定砦への合法到着・保持の履歴 | 一時通過と保持を区別。現在は履歴が保存されない |
| 予定ターン内到達 | 採用された期限とvictory/到着turnを比較 | 全戦場への時間制限の採用ではない。後から期限を決めて成功扱いにしない |
| 残存部隊・永久ロスト | unitsの生存、metrics.deaths、lost、named | 予備・一般兵補充・次章復帰を区別。生存だけで人物との会話成立は保証しない |
| 本城に残した部隊 | turnごとの位置・役割・本城防衛継続 | 近くにいた事実と、救った因果は別。章間の永続化には別仕様と移行検査が必要 |

今回はこれらをゲームへ表示・永続化しない。セーブ形式、章間継承、将軍、最終章、二正面戦闘、救援イベントは対象外。iPhone実機・聴感・人間による難度評価は未検証。
