# 戦線指揮 — FIELD COMMAND

スマートフォン縦画面で遊ぶ、決定論のオリジナルSRPGプロトタイプ。4フェーズ、有限の戦術スキル、動かずに行う援護・回復、連戦での永久離脱を試します。FEに着想を得ていますが、画像・音楽・キャラクター・コードは流用していません。

**テストプレイ**：https://hane-san.github.io/SRPG/ （公開・起動確認済み）  
**ソースの正本**：https://github.com/hane-san/SRPG  
現在の版：0.5.1。バージョンはメニューの「このゲーム・検証記録」に表示。

## v0.5.1の操作

矢印を描いてから敵へフリックすると、描いた矢印の終点から攻撃します。途中のマスや別の射撃位置に勝手に変えません。届かない敵は射程外と表示し、攻撃を無効にします。移動先を変えるときは空きマスで離して選び直します。攻撃・待機・戻るの窓は移動先の近くに矢印付きで表示します。

移動は地形印を残した統一した青、外周は明るい縁どり。移動後に通常攻撃できる範囲は青の外側の赤い発光領域です。これはP3の待機射撃とは別です。攻撃音は短い打撃・金属音を重ねた合成音に調整しています。


新規戦闘ではシューター「ニコ」（HP10・攻9・守1・移3）が加入。通常攻撃2〜3マス、動かず待機したP3に距離1〜5の敵全員へ1発ずつ攻撃します。人数によらず1ターンの発動で1回分だけ消費、残2回。旧保存の部隊は維持するため、すぐ使う場合は新しく戦闘を開始してください。

05「森壁の回廊」は雨なし・雨なし・小雨・大雨・小雨の5ターン周期。P4を越えて次のターンへ切替。小雨の移動は歩兵−2/騎兵−3、大雨は−3/−4、敵味方とも最小1。天候に合わせて青い移動範囲・敵AI・危険域・経路も変わります。マップごとに色調も分けています。


表示ツールは左下の「表示」で開閉。常設案内を消し、命令窓は移動元・移動先・対象を避ける配置と半透明に変更しました。兵種はシルエットと漢字記号で表示。弓は通常2マス、動かず待機したP3は2〜3マスで、隣接攻撃はできません。矢の向き・飛翔と魔法を区別しています。

追加戦場：04 長河の三橋（12×40・味方11／敵13）、05 森壁の回廊（16×36・11／13）、06 暁の城塞線（14×44・13／15）。メニューから単体で開始できます。連戦は第1〜3章のままです。


青い部隊を**押したままスライド**。指に合わせて矢印が伸び、離すと **攻撃・待機・戻る**。
そのまま敵マスまで滑らせると、移動先を保って攻撃対象を選びます。
攻撃／待機を一度押すだけで実行。戻るは消費せず取消。その場なら部隊をタップするだけ。
複数の敵が射程内なら↻で対象を切り替えます。攻撃予測には双方の結果HPと離脱警告を表示。

- 地図の空き場所や青範囲外からのドラッグは地図移動。スライド中に指を端へ寄せると自動スクロール。
- 長押し・スライドはゲームが処理し、地図内でブラウザの選択・メニュー・ページスクロールを起こさない。
- 味方も敵も経路のマスを順に移動。攻撃→反撃を別々に表示。敵は一隊ずつ移動・戦闘を終える。
- 半透明の命令ウィンドウ。ボタンは44px以上。画面の「音」で効果音のON/OFF、メニューで通常／高速を切替。
- キー操作：矢印で移動先、Enterでメニュー、Aで攻撃実行、Wで待機実行、Escで取消、Nで次の未行動部隊。
- 「命令終了」で敵軍→待機支援→予告イベント。「詳細」で能力・支援対象・回数温存を設定。
- クラシックは離脱を次章へ継承。カジュアルは次章で復帰。再試行は章開始時の編成・設定に戻る。
- 確定したP1命令と勝敗を端末保存。演出中に再読込しても確定した命令を復元。0.2.0・0.3.0の保存も引き継ぐ。
- 北城への移動で勝利。第2章は本陣への敵侵入で敗北、南城の制圧で増援停止。

## ルール

| フェーズ | 内容 |
|---|---|
| P1 味方 | 移動＋攻撃／待機。動かず待機するとP3スキルを準備 |
| P2 敵軍 | 敵の移動・攻撃、射程が合う味方の反撃 |
| P3 支援 | 生存する味方の待機射撃・回復。射撃への反撃なし |
| P4 戦場 | 前ターンに予告した砲撃・増援、次の予告 |

**動かず待機**した部隊はP2反撃をせず、P3に1回だけ自動スキルを使います。前衛・魔道・騎兵は通常射程で攻撃、弓は待機時だけ射程2〜3。祈祷・救護は上下左右で隣接する味方全員を各7回復。自分・敵・斜めは対象外。何人回復しても、そのターンの発動で使うのは1回分です。P3攻撃への反撃はありません。移動後の待機とP1攻撃の後にはP3スキルは発動しません。未操作のまま命令終了した部隊も、その場で待機する扱いです。

効果が出た時だけ1回消費し、対象なしは消費0。攻撃スキル0回の部隊は通常待機になりP2反撃が戻ります。回復スキル0回ではH1ならHP半分まで+1の応急回復。対象は自分以外です。

支援の優先順：指定対象が射程内なら優先 → 攻撃は撃破できる敵・攻撃力順／回復は隣接全員 → 座標順。敵移動後にも手動優先対象へ届く保証はありません。回復はHPが1でも減っている隣接味方を全員対象にし、対象がいなければ消費しません。回復の単体優先指定は不要です。「詳細」で回数を温存できます。温存中も構えによるP2反撃放棄は維持されます。

ダメージ `max(1, 攻撃 − 守備 − 地形)`。命中100%、必殺・追撃・属性相性・射線遮蔽なし。森は移動コスト2・守備+1、砦は守備+1。敵・水域・岩壁は通過不可、味方は通過できても同じマスに止まれません。移動の矢印と確定可否には同じ移動コストを使います。

## 3つの試験マップ

| マップ | 試す判断 | イベント |
|---|---|---|
| 霧河の渡し 12×20 | 正面の橋で連携／東の細橋へ騎兵を回す | なし |
| 二つの戦線 16×30 | 本陣防衛／北城速攻／南城を先に取る／東道へ別働隊 | T4・8・12…に南から1隊、南城制圧で停止 |
| 灰城の砲火 14×26 | 後衛警戒／回復のため停止するか砲撃から退避するか | 砲撃T3・6・9…、増援T4・8に各2隊 |

敵の出現位置は前ターンP4で確報、出現後は翌ターンP2から行動。砲撃は次のP1を丸ごと与えたうえで、予告の赤枠の全員に固定6ダメージ（敵にも当たる）。砲撃標的は予告時に最も南の味方、同率なら西側。増援地点の占有はその部隊の到着を中止します。

## 編集とローカル実行

Node.js 22以降、Python 3があれば動きます。実行時の依存パッケージはありません。

```sh
git clone https://github.com/hane-san/SRPG.git
cd SRPG
npm run dev
# http://localhost:4173
npm run check
npm run simulate
```

| ファイル | 主な編集内容 |
|---|---|
| `config.js` | HP・火力・射程・回数・回復量など |
| `data.js` | 3マップの地形・配置・目的地・増援位置・初期部隊 |
| `engine.js` | 移動・戦闘・敵AI・4フェーズ・勝敗の処理 |
| `app.js` / `style.css` | 命令UI・メニュー・連戦 |
| `ui-input.js` / `ui-model.js` / `save.js` | 連続スライド・攻撃予測・未行動巡回・保存の検証 |
| `playback.js` / `audio.js` | 経路の補間・攻撃と反撃の順次表示・効果音 |
| `render.js` | 手続き生成のオリジナル仮ドット絵・範囲・全体図 |
| `tests/` | ルール・ブラウザ・簡易方策の再現試験 |
| `docs/balance.md` | 採用理由・検証結果・残る問題 |
| `AGENTS.md` / `CLAUDE.md` | GPT / Codex / Claude Codeの共通契約と読込入口 |

マップ座標は0始まり、UI表示は1始まり。スキル枠は兵種ごとに1つ。新規ルールを足す前に、配置と数値で調整します。

任意のブラウザテスト：

```sh
npm install --no-save --package-lock=false playwright@1.57.0
npx playwright install chromium
# 別ターミナルで npm run dev
node tests/browser-check.mjs
node tests/interaction-check.mjs
node tests/overlay-check.mjs
```

`?debug=1` はテスト用の状態スナップショットを公開します。通常プレイには不要です。`test-results/` に検証画像と結果を出力（git対象外）。

## 公開・更新

GitHub Pagesは **Deploy from a branch / main / (root)** で公開済み。以後mainへのpushで更新されます。`.github/workflows/check.yml` はルールのCI検証です。Pages用のビルドツールは不要。

```sh
node scripts/release.mjs 0.5.1
npm run check
git add .
git commit -m "Tune SRPG balance"
git push origin main
```

リリーススクリプトがモジュール・CSSの更新パラメータを揃え、古いファイルとの混在を防ぎます。Service Workerの固定キャッシュはありません。メニューの「最新版を確認」から更新でき、Pagesの反映には待ち時間があります。コードを編集しただけで版を上げない運用は避けてください。

検証の根拠と限界は [仕様・バランス検討](docs/balance.md) を参照。iPhone/Android実機のOS固有操作やFPSは未計測です。

## v0.2.0 攻撃／待機と指操作

命令は攻撃／待機の2つ。従来の堅守・破陣・疾駆・即時回復はこの試作では外し、各部隊の有限回数をP3攻撃／回復に統一しました。兵種のHP・攻守・移動と地形・増援配置は維持しています。

- タップ／スライドで仮移動先を選び、薄い経路矢印と仮の駒を表示。
- 仮の駒から敵のマスへのフリックは、敵タップと同じ対象選択。射程外は確定不可。操作だけで攻撃や消費は発生せず、最後に明示確定。
- 指の中断・2本目の指・フォーカス喪失時は、ドラッグ前の仮指定に戻す。
- メニュー・命令・詳細は地図の上の窓。開閉しても地図の大きさ・位置を固定。主要なタップ領域44px以上。

検証は [v0.2.0の操作・バランス記録](docs/mobile-ui-0.2.0.md)。以前の画面記録：[v0.1.1](docs/mobile-ui-0.1.1.md) / [v0.1.2](docs/mobile-ui-0.1.2.md)。
