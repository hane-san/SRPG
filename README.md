## 新しい遊び方（v0.8.0）

### 出撃と帰還
**全味方が本城から出撃する試作（PR #31、未マージ）**。全員が城内の予備で開始し、開始時の盤面に味方は0隊。城をタップ→兵種アイコンと名前で選択→城から移動先へスライド。移動先を確定すると城に現れる短い金属音と「出撃する！」の一言の後、指定経路へ移動します。初ターンのみ2隊まで出撃、2ターン目以降は毎ターン1隊、同時最大5隊。命令確定前は出撃枠も保存も変わりません。予備隊は盤面を占有せず敵から狙われません。

城の1マス以内で未行動の味方には「帰還」コマンドを表示します。城まで移動するのは通常の移動操作（自動帰還は今後の課題）。帰還後は予備として再配置でき、後方の守りや別戦線への展開を考えられます。

### HP6・固定ダメージ
- **最大HPは全部隊6**。盤面の駒の下に6マスで可視化します。
- 下級歩兵の基本攻撃は2。下級弓兵も射程2で2。上級の近接は基本3。
- シューターは射程2で2、射程3では1。専用の上級弓兵分岐は構想段階。
- 防御ステータスの加算競争ではなく、盾槍隊だけ被ダメージ−1、上級で−2。最低ダメージ1。森は移動コスト2だがダメージ軽減はありません。
- 命中は確定、必殺・追撃・相性乱数はなし。敵味方とも同じ戦闘規則です。
- 終盤の4〜5ダメージの強敵は、今後のマップ・物語で少数だけ実装する構想。現在の3章のボスは基本3です。

### P1〜P4
| フェーズ | 内容 |
|---|---|
| P1 | 味方の出撃、移動、攻撃、待機、城帰還 |
| P2 | 敵の移動・攻撃と、射程内で構えていない味方の反撃 |
| P3 | 味方砲兵・魔術師系が、P1で移動せず待機した場合のみ砲撃／治療 |
| P4 | 予告砲撃・増援・天候などの戦場イベント |

**P3専門支援の実験**：砲兵（シューター）は静止待機で射程内の敵1隊を砲撃。魔術師系（既存の魔道隊・祈祷隊・救護隊）は静止待機で隣接負傷味方1隊をHP2回復。これら専門職は味方P1で通常攻撃できず、P2でも反撃しません。移動したターンはP3を使えません。通常歩兵・重装・弓・騎兵は従来のP1通常攻撃/P2反撃のみで、P3効果なし。弾薬は専門職だけ最大2、効果時だけ1消費。**本城の周囲1マスにいる専門職はターン開始時に弾薬を1補給**。敵魔道隊のP2攻撃は、この初回試作では維持します。

### 永続ロストと昇格
クラシックモードでネームドが戦死すると、その人物は連戦に復帰しません。しかし**次章には同兵種・同ランクの一般兵が同じ編成枠を引き継ぐ**ので、基本戦力は失われません。戦死による修理費や報酬減額はありません。

全員が上級職へ成長する段階では標準性能は同等ですが、生存ネームドのみ仮の追加技能（護衛／機動／迎撃）を3択で習得できます。第1〜3章の連戦では第2章クリア後に選択。一般兵は標準上級職の性能まで。報酬による別種の装備や外伝等は今後検討する仕組みです。

カジュアル（次章復帰）もデバッグ・比較用に残しています。

### 基本操作
部隊から合法な移動先へ指を滑らせ、そこで約0.2秒保持すると短いSEと発光で移動先が固定されます。指を離すと移動＋通常待機、保持したまま射程内の敵へ続けて滑らせて離すと直接攻撃します（反撃と残HPは離す前に画面下へ表示）。移動だけの直後は右下の半透明「↶」で一手戻せます（次の行動・敵フェーズ開始まで）。素早く指を離してまだ固定されていなければ、従来の攻撃／待機／戻るメニューで選び直せます。空きマス2タップとキーボード操作は代替手段として維持します。命令パネルは盤面の外で、開閉してもカメラが動きません。端へのスライドでスクロールできます。

戦闘前は双方の残HPと反撃を確認でき、戦闘後は画面下に直近の結果が残ります。音楽は初期OFF、効果音は初期ON。6マップの計12曲＋既存候補14曲＋新規の哀愁・勇壮系16曲＝全42曲。サウンドルームですべて固定番号 No.01〜42 から試聴できます。番号は曲ごとに不変なので、「マップ03の味方を No.37、敵を No.42」のように割当を指定できます。現行マップへの曲の割当は変更していません。全曲一覧は [BGM番号カタログ](docs/music-catalogue.md)。

## 宝石のHP6演出（Issue #28 の試作）

HPを6個の結晶として扱い、ダメージの**実減少量**だけ盤面のジュエルが1個ずつ「パリン」と砕けます。通常の1〜3は軽快な破砕音、4以上の強打は短いヒットストップと鈍い初撃の後に速く破砕します。重装の軽減を受けたときは鈍い受け止め音を混ぜつつ、実際に失われる数だけ破砕。最後の1個が砕けると結晶状に駒が崩れ、味方の戦死と敵撃破は余韻を変えます。回復は逆にジュエルが再生します。音楽・戦闘数値・HPルール・セーブ構造は変えていません。

**試聴・試遊**：ゲームの「メニュー」→「💎 宝石の破砕音を試す」。1〜5ダメージ、重装、HP2への致死打、味方戦死、2ジュエル回復をその場で聴き比べられます。戦闘を消費しません。SE OFFなら無音。シミュレータでの表示とiPhoneの実際の音質・触り心地は別に確認してください。

### 戦場HUDの可読性改善（Issue #50）

- 画面上部に**4つの細いフェーズレール**：Ⅰ味方・Ⅱ敵軍・Ⅲ待機支援・Ⅳ戦場更新のうち、現在位置だけ発光。ヘッダーの高さは従来どおり縦52px・低い横画面48pxでマップを狭めません。
- 砲撃予告は**赤茶色で警戒表示**、増援は紫、天候は落ち着いた色に分離。長文は72pxの領域内をスクロールして確認できます。
- HP予測と戦闘報告は、正確なHP数字と残量バーを残し、**6つの結晶の目盛り**を重ねることで「1個割れた」の意味を統一しました。
- 移動を指で編集している間は、**敵への攻撃候補・移動先確定・不正な射程**を命令欄の控えめな縁色でも区別。テキストやタップ/キーボードの操作は残しています。

UIの色や情報の整理だけであり、4フェーズ・HP6の戦闘計算・出撃枠・カメラ操作・144px命令欄・セーブの仕様は変えません。iPhone実機の視認性は今後試遊で確認します。

## マップと連戦
01「霧河の渡し」→02「二つの戦線」→03「灰城の砲火」が連戦。04「長河の三橋」、05「森壁の回廊」（雨）、06「暁の城塞線」は単体の実験用マップ。敵の初期配置は元の試作を引き継いでいるため、全味方を本城から投入する新試作とHP6にふさわしい再調整・難易度検証が今後必要です。

## セーブ互換性
戦闘規則とHP構造を変更したため**v0.7.0以前の途中セーブは復元しません**。新しいマップ・連戦を開始してください。設定・音量は別に保存されます。v0.8.0からの進行は同じ版の安定状態を保存できます。

## シナリオ構想について
最終章の将軍の自己犠牲、勝利状況による回想・会話の厚み、外伝・隠しキャラ、世界観の深掘りは[仕様書](docs/hp6-campaign-design.md)に記録し、**現段階ではイベントや物語分岐を実装していません**。どの展開でも結末は共通だが、プレイヤーの戦果で知り得る真相が増える方針です。
